Privacy Policy — Prompt Whisperer

Effective date: August 20, 2026

Prompt Whisperer ("the extension") is a Chrome extension that helps you create, organize, search, and optimize AI prompts from a browser side panel. This policy explains what data the extension handles, where it is stored, and when — if ever — it leaves your device.

1. Data the extension stores

All of the following is stored locally in your browser profile using Chrome's chrome.storage.local API. It is never uploaded to any server operated by the developer of Prompt Whisperer, and the developer has no access to it:

  • Prompt text, titles, categories, tags, notes, and favorite status that you create
  • Your app settings (appearance, default view, click behavior, import/export preferences)
  • If you choose to use the optional live AI optimization feature: the Anthropic API key you provide, and your selected model

This data stays on the device it was created on. It is not synced across devices, not backed up by the extension, and is removed if you uninstall the extension or clear your browser's site/extension data. You can also erase it yourself at any time using the "Reset to sample data" option, or by deleting individual prompts and categories.

2. Data sent to third parties

By default, Prompt Whisperer's "Optimize Prompt" feature runs entirely offline using a built-in mock optimizer — no data leaves your browser.

If you explicitly switch Settings → AI Provider to "Anthropic (Claude)" and supply your own Anthropic API key, then when you click "Optimize":

  • The prompt text you are optimizing, your selected optimization goal, and any additional instructions you typed are sent directly from your browser to Anthropic's API (api.anthropic.com).
  • Your API key is sent along with that request, directly to Anthropic, to authenticate the call.
  • This request goes straight from your browser to Anthropic — it does not pass through, or get logged by, any server operated by the developer of Prompt Whisperer.

Use of Anthropic's API is subject to Anthropic's own privacy policy and terms. No data is sent to Anthropic, or any other third party, unless you have turned on this optional feature and actively click "Optimize."

3. The "Insert into active tab" feature

When you insert a saved prompt into a text field on a webpage (for example, a chat box on ChatGPT, Claude, or Gemini), the extension writes that text directly into the focused field on the active tab using Chrome's scripting API. This happens entirely within your browser — no data about the page you're on, or the text inserted, is transmitted anywhere or logged by the extension.

4. What we don't do

  • We do not collect analytics, usage statistics, or telemetry of any kind.
  • We do not use tracking pixels, cookies, or third-party advertising SDKs.
  • We do not sell or share your data with advertisers or data brokers.
  • We do not read the content of pages you browse, except to insert text into a focused field when you explicitly trigger that action.

5. Permissions this extension requests, and why

  • storage — to save your prompts, categories, tags, and settings locally.
  • sidePanel — to display the extension's interface in Chrome's side panel.
  • activeTab / scripting — to insert prompt text into the page you're currently viewing, only when you choose to do so.
  • Host permissions (all sites) — the side panel can be open while you're on any website, and the "insert into active tab" feature needs to be able to act on whichever site you're currently using (ChatGPT, Claude, Gemini, or any other page with a text field). Chrome's activeTab permission alone does not extend to actions triggered from the side panel, which is why broader host access is requested. This permission is used only to insert text you explicitly choose to insert — never to read, monitor, or transmit page content.

6. Children's privacy

Prompt Whisperer is not directed at children and is not intended for use by anyone under 13.

7. Changes to this policy

If this policy changes — for example, if a new AI provider or feature changes what data is collected or where it's sent — this page will be updated and the "Effective date" above will be revised. Material changes will also be reflected in the extension's Chrome Web Store listing.
